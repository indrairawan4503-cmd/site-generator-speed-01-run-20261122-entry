A faster drop-in for makefun-site 1.0.0: `solve.js` rebuilds the static site generator as a single-pass streaming pipeline — Markdown is lexed and rendered in one fused pass straight into string arrays joined once, templates render into a shared buffer, and inline markup scans with `indexOf`/`charCodeAt` fast paths. No dependencies, no network.

## Run

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`), answers each one with `run()` from `solve.js`, and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
